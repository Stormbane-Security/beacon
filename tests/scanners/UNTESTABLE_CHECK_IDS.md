# Untestable Check IDs in Drydock

Check IDs that cannot be tested in Docker-based drydock integration tests due to
infrastructure requirements, platform dependencies, or needing specific vulnerable
software versions that are not safely containerizable.

## Web Application (requires specific application servers)

| Check ID | Reason |
|---|---|
| `web.iis_shortname` | Requires IIS/.NET Windows server |
| `web.ognl_injection` | Requires Apache Struts/Confluence (Java) |
| `web.spel_injection` | Requires Spring Framework (Java) |
| `web.el_injection` | Requires JSP/JSF container (Java) |
| `web.xsd_injection` | Requires XML Schema processing endpoint |
| `web.http_request_smuggling` | Requires specific frontend/backend proxy mismatch (CL.TE/TE.CL) |
| `web.pdf_ssrf` | Requires PDF generation endpoint (wkhtmltopdf, Puppeteer, etc.) |
| `web.redos` | Requires regex-heavy endpoint with backtracking-vulnerable patterns |
| `web.prototype_pollution` | Requires vulnerable Node.js application with prototype chain exposure |
| `web.second_order_xss` | Requires multi-endpoint app where injection in A appears in B |
| `web.second_order_sqli` | Requires multi-endpoint app with stored SQL injection path |
| `web.second_order_reflection` | Requires multi-endpoint app with stored reflection |
| `web.dns_rebinding_internal_routable` | Requires DNS infrastructure for rebinding attack |
| `web.cors_null_origin` | Requires app that reflects `null` Origin with credentials |
| `web.cors_preflight_misconfiguration` | Requires app with misconfigured preflight OPTIONS |
| `web.default_credentials` | Partially tested via Grafana/other tests; generic web form needs specific app |
| `web.horizontal_privesc` | Requires multi-user app with broken access controls |
| `web.incomplete_auth_flow` | Requires multi-step auth process that can be skipped |
| `web.method_bypass` | Requires app with method-based access controls |
| `web.race_condition_no_idempotency` | Requires stateful app with TOCTOU race condition |
| `web.step_bypass` | Requires multi-step workflow (checkout, registration) |
| `web.ssrf_redirect_metadata` | Requires app with SSRF via redirect to cloud metadata |

## TLS (requires specifically vulnerable OpenSSL versions)

| Check ID | Reason |
|---|---|

## SAML (requires real SAML IdP with specific misconfigurations)

Deep SAML checks are asserted against Keycloak in `saml.yaml` but some require
very specific IdP misconfiguration that Keycloak dev mode may not expose:

| Check ID | Reason |
|---|---|
| `saml.xxe_injection` | Keycloak properly rejects XXE; need a broken SAML parser |
| `saml.xml_signature_wrapping` | Keycloak validates XML signatures; need a broken implementation |
| `saml.open_redirect` | Keycloak validates RelayState; need misconfigured SP |
